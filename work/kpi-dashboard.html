A dashboard over the marketing sheet, so "how are we doing?" stops costing somebody an afternoon.

The problem

Every question meant opening the spreadsheet

The data existed. Getting an answer out of it meant knowing which tab, which filter and which column — so in practice one person answered everyone else's questions, and the questions that were mildly inconvenient to ask simply went unasked.

The engineering

The decisions that actually mattered

One number decides everything

The dashboard leads on cost per lead, not a wall of engagement metrics. Ten numbers nobody acts on is a worse dashboard than one number everybody argues about — and cost per lead is the one that actually pays the bills.

No second copy of the data

It reads the live sheet directly. A dashboard with its own database is a dashboard that will eventually disagree with the source, and then nobody trusts either.

Built for someone who won't open a spreadsheet

Filters instead of formulas, sortable columns instead of pivot tables. The measure of success is a director getting their own answer without messaging anyone.

Slow and honest beats fast and stale

Where a choice existed between caching for speed and reading fresh, it reads fresh. A dashboard showing yesterday's number confidently is the failure mode that costs trust.
